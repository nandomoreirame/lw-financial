# US-022: Mensagens de Erro

**Como** usuário do sistema
**Eu quero** receber mensagens de erro adequadas
**Para que** eu possa entender o que aconteceu e corrigir o problema

## Critérios de Aceite:

- Deve exibir mensagens de erro para operações inválidas
- Deve mostrar mensagem para saldo insuficiente
- Deve mostrar mensagem para conta inexistente
- Deve mostrar mensagem para credenciais inválidas
- Deve mostrar mensagem para token expirado ou inválido
- Mensagens devem ser claras e objetivas
